## 📌 Featured Projects

- **[/transcribe](https://github.com/joshuazesu/transcribe)** · Claude Code skill<br>
  *I'm a slow note-taker, so I built a skill that does it for me. Give Claude a recording and it transcribes it on your Mac with whisper.cpp, labels every line with a speaker name using pyannote voiceprints, then summarises the decisions and action items. A guided setup installs everything, and the audio and voiceprints never leave your Mac.*

- **[Workout Tracker (LogMyLift)](https://github.com/joshuazesu/workout-tracker)** · iOS & Android app<br>
  *A Hevy-style workout tracker built with Expo, React Native and TypeScript. Log sets from reusable templates, browse a 54-exercise illustrated library, track your history on a calendar and earn trophies for consistency. Every change saves on the phone first, then syncs to your account on Supabase in the background, so it works offline.*

- **[Prompts Graph](https://github.com/joshuazesu/prompts-graph)** · Claude Code plugin<br>
  *A GitHub-style contribution graph of every prompt you send Claude Code, with yearly totals, streaks and switchable colour palettes. It's private by default: it stores only daily counts and prompt IDs, never what you type, and makes no network calls.*

- **[S&P 500 Market Direction Predictor](https://github.com/joshuazesu/sp500marketpredictor)** · Machine learning<br>
  *A Random Forest model that predicts whether the S&P 500 will close higher tomorrow. Built with Python and scikit-learn on 30+ years of data, with engineered technical indicators, rolling-window backtesting and 57.7% precision on up-day calls.*
